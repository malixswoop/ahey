## Ahey Contributions

Before considering any contributions, please note the following guidelines.

## Current Contribution Status

Ahey is **not currently accepting code contributions**.

The main reason for making the source code available is:

- To enable others to use it for personal projects or to explore its functionality.
- To ensure transparency in the code, maintaining the app's integrity.

### Support the Project

If you'd like to support Ahey and its ongoing development, please consider sponsoring through [Github Sponsors](https://github.com/sponsors/vasanthv). Your support helps with the development and maintenance of the app and is greatly appreciated!
